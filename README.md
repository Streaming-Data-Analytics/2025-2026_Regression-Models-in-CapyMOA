## Project Overview
This project focuses on extending **CapyMOA** by integrating **regression models** from the **River** library.

The goal is to enhance the regression capabilities of CapyMOA by:
- wrapping regression base learners from River,
- implementing missing regression models in MOA,
- enabling consistent evaluation of regression tasks in streaming scenarios.

## Background
While CapyMOA provides strong support for classification tasks, its support for **regression in streaming settings** is more limited.

River, on the other hand, includes several efficient online regression models that are not currently available in CapyMOA.

Additionally, some important regression models commonly used in data stream mining (e.g., **Hoeffding Tree Regressor**) are missing or not fully integrated in CapyMOA.

This project aims to:
- extend CapyMOA with regression capabilities,
- bridge the gap with River,
- provide a consistent framework for streaming regression evaluation.

## Goals and Objectives
The project is divided into four main parts:

### 1. Model Integration (Core Task)
Select and implement a subset of the following River models:

- Hoeffding Adaptive Tree Regressor
- Bagging Regressor
- SRP Regressor
  
The implementation must follow this pipeline:

- Re-implement (or adapt) the model in **Java (MOA)**
- Ensure compatibility with MOA streaming interfaces
- Wrap the Java implementation in **CapyMOA (Python)**
- Make the model usable within CapyMOA pipelines (e.g., prequential evaluation)

### 2. Cross-Framework Comparison
Evaluate the implemented models in both River and CapyMOA. The comparison must be performed on state-of-the-art dataset and must include:

- Regression performance (e.g., MAE, RMSE);
- Consistency between implementations
- Discussion of any discrepancies

### 3. Computational Performance Analysis
Compare execution efficiency between River and CapyMOA:

- Training and Inference time
- Memory usage

### 4. Integration in CapyMOA Tutorials
Reproduce and extend selected tutorials from https://capymoa.org/tutorials.html.

Requirements:
- Run at least 2 tutorials
- Include the newly implemented model(s) in the comparison
- Analyze how the new models behave compared to existing CapyMOA learners

## Datasets
